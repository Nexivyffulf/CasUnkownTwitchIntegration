To install this mod, add the folder "TwitchItegration" to "...BepInEx/plugins". This folder name is important.



To enable, find the setting in the settings menu under gameplay. Pressing the button will open a webpage.

For this next part you will need to click back into the game occasionally to let the code run.

There authorize "Grey Planet Live Feed". You will be asked to log into Twitch if you are not already.

If you are a twitch affiliate it should "hopefully" work.


Adding redemptions:

For now, this must be done manually, there are two to mention. How you set them up is loose and only requires a few keywords
in the description to work. Name, cost, and all other things can be whatever you want.
Keywords can be any case.

Give item:

starts with "give"
ends with the name of the item you want

Give random item:

starts with "give"
has the word "random" anywhere in it
may end with the pool, valid pools are below


medical
food
water
tool
drug
container
utility
custom
